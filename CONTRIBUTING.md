# Contributing

- Use Node.js 24.18 (`nvm use` reads `.nvmrc`), then `npm ci`.
- Before opening a PR, run `npm test`, `npm run typecheck`, `npm run lint`, and `npm run build`.
- Keep PRs small and focused. Add tests for new logic.
- Read [AGENTS.md](AGENTS.md) and [CONTEXT.md](CONTEXT.md) for project conventions.
